# Display Technologies — brand playbook

Display Technologies (DT) is one of the six SRND brands (`../../group-strategy/commercial-model.md`):
**solutions for the architectural integration of technology** — screens and masking, mounts and
mirrors, airflow and enclosures, port holes, and the modular Screen Wall, with the control engineered
inside the products. Deliberately **not** "the projection company": the competence is integration and
precision manufacture, and it carries forward to LED.

This playbook holds only what is specific to DT; the structural strategy is inherited from
`../../group/` (buyer journey, execution standards, commercial model, content placement, channels).

## Status

- **`positioning.md`** — **the settled phase-1 brand strategy.** Seven sections, each a publishable
  positioning core plus the internal reasoning: what DT is, whose problem it solves, the promise, why
  it's credible, the discipline, how it fits the group, what's still open. Read this first; it governs
  everything else here.
- **`product-line.md`** — the product range catalogued from the live website (52 products), grouped by
  function, with the strategic reads.
- **`brand-data.md`** — raw data captured from the DT website and group site (facts, current state).
- **`dt-commander-v5.md`**, **`competition-matrix.md`** — platform and competitive captures.
