# Display Technologies — brand playbook

Display Technologies (DT) is one of the six SRND brands (`../../group/09-brand-portfolio.md`):
projection installations end to end — screens, mounts/mirrors, airflow and enclosures — with a
"design for install" focus.

This playbook holds only what is specific to DT; the structural strategy is inherited from
`../../group/` (buyer journey, execution standards, commercial model, content placement, channels).

## Status

- **`brand-data.md`** — raw data captured from the DT website and group site (facts, current state).
- **Messaging not yet agreed.** What we *want DT to say* (positioning, the story, the differentiators
  we lead with) is still to be worked out with the team, per the agreed sequence: settle the message
  before planning any new website. Until then, treat `brand-data.md` as input, not settled voice.
