# ADR 0022 — One content estate, not a marketing estate and a support estate

- **Status:** **Rejected** — 2026-08-17, Neil.
- **Source:** `proposals.md` via ADR 0008, split to one decision per ADR.

## Decision

**One content estate.** The same material does four jobs: hook, de-risk, install support, next order. **The support question and the pre-purchase doubt are the same question at different times.**

*This is also why documentation was underfunded: marketing did not own it because it looked like support, and support did not invest because it looked like marketing.*

## Provenance

**Was `S13`**, then part of ADR 0008 before the split.
