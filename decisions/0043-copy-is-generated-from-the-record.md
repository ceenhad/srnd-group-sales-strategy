# ADR 0043 — Website copy is generated from the product record, not written per page

- **Status:** **Proposed** — 2026-08-17. **Not accepted.** Only Neil moves this to `accepted` (ADR 0001 §3).
- **Source:** `proposals.md` via ADR 0014, split to one decision per ADR.

## Decision

**Copy is generated from the record.**

*The C-ATS Shopify site kept its theme placeholder hero because there was no canonical source for what belongs there, and the 3 Rs vanished from the homepage for the same reason.*

**Was `S19`**, then part of ADR 0014 before the split.
