# ADR 0044 — Support is a documentation problem, not a staffing one

- **Status:** **Proposed** — 2026-08-17. **Not accepted.** Only Neil moves this to `accepted` (ADR 0001 §3).
- **Source:** `proposals.md` via ADR 0015, split to one decision per ADR.

## Decision

**Support reduces to two things: the dealer being trained, and the answer being available when they need it.** Manuals and instructions are therefore the priority content class.

## Provenance

**Was `S11`**, then part of ADR 0015 before the split.
