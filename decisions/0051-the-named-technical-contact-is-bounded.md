# ADR 0051 — The named technical contact is bounded

- **Status:** **Proposed** — 2026-08-17. **Not accepted.** Only Neil moves this to `accepted` (ADR 0001 §3).
- **Source:** `proposals.md` via ADR 0016, split to one decision per ADR.

## Decision

**Bounded deliberately**, or it rebuilds the trap that made field sales fail: every question routing to the scarce person. It works only with the routine answers already published, so the contact handles judgement rather than repetition.

## Provenance

**Was `P4`**, then part of ADR 0016 before the split.
