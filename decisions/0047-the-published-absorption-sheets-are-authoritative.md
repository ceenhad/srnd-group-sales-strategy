# ADR 0047 — The published C-ATS absorption sheets are authoritative

- **Status:** **Proposed** — 2026-08-17. **Not accepted.** Only Neil moves this to `accepted` (ADR 0001 §3).
- **Source:** `proposals.md` via ADR 0015, split to one decision per ADR.

## Decision

**The published sheets on `c-ats.co.uk` are authoritative** — the figures that have been out for years. **The apparent conflict dissolves:** the REF-CP chart already plots Reflection A and Reflection B, so the two number sets are the two install types, not rival versions of one figure.

## Provenance

**Was `S21`**, then part of ADR 0015 before the split.
