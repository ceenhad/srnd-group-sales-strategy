# ADR 0055 — Control is embedded in DT products, never a line item

- **Status:** **Proposed** — 2026-08-17. **Not accepted.** Only Neil moves this to `accepted` (ADR 0001 §3).
- **Source:** `proposals.md` via ADR 0017, split to one decision per ADR.

## Decision

**The Commanders sell only inside the products.** Selling controllers alone would make DT a components supplier, and a Commander a competitor can buy is a Commander they can fit to their own mechanism.

## Provenance

**Was `B4`**, then part of ADR 0017 before the split.
