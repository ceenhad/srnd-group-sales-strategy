# ADR 0036 — Communication has no start and no end

- **Status:** **Proposed** — 2026-08-17. **Not accepted.** Only Neil moves this to `accepted` (ADR 0001 §3).
- **Source:** `proposals.md` via ADR 0011, split to one decision per ADR.

## Decision

**Communication has no start and no end.** Project lead times run to a year, so a sequence opens an ongoing relationship — never a campaign that stops. **Dedicated campaigns are capped at three mails in two weeks** unless transactional, and **the human ask triggers on a signal, not a calendar.**

## Provenance

**Was `S28`**, then part of ADR 0011 before the split.
