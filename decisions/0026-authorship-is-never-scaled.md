# ADR 0026 — Authorship is never scaled

- **Status:** **Proposed** — 2026-08-17. **Not accepted.** Only Neil moves this to `accepted` (ADR 0001 §3).
- **Source:** `proposals.md` via ADR 0008, split to one decision per ADR.

## Decision

**Authorship is never scaled.** No bulk or generic content; **volume is not the goal.** The archive is legitimate because it is our own authored answers.
