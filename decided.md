# Decided

**A decision exists here only if it went through the question box and a human answered it.** *Neil, 2026-08-20:
"It becomes decided only when it goes through the question box and is answered. That's it. The gate is a human
verifies the decisions."*

**This file is an index, not a record.** *Each row names what was settled and points at the `registers/questions.md`
row where the answer sits **in the owner's own words**. Nothing is paraphrased here — a second copy of the decision
record is what emptied this file on 2026-08-16, because the copy got cited as authority and had drifted.*

**What does not belong here:** *a session's conclusion · a proposed default nobody ratified · an inference from a
document · something that "follows obviously" from a decision. **If it was not asked and answered, it is not
decided** — it stays a question until it has been.*

**Adding a row:** *ask it in the box · record the answer verbatim in `registers/questions.md` · add one line here.
In that order.*
