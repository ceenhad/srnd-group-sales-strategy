# The QA sheet — 46 rows, three questions each

**What this is: the thing you fill in.** `10-tasks.md` is the register and carries the reasoning. This is one
sitting's worth of paper — 46 rows, three answers each, roughly an hour.

**Why not "do you do this?"** Because the answer is mostly yes. SRND does the work; it is structure and
consistency that kill it. Confirming that each task exists would confirm nearly every row and change nothing.

## The three questions

| | Question | Answers |
|---|---|---|
| **A** | **Is it the same every time?** | `standard` — same way each time · `varies` — depends who does it · `from scratch` — rebuilt each time |
| **B** | **What starts it?** | `a system` — something fires it · `remembered` — someone thinks of it · `asked` — only when a customer prompts |
| **C** | **Where does the output land?** | `a system` — engine, the store, the record · `a file` — somewhere findable · `a head` — one person's memory or inbox · `nowhere` |

**Answer fast.** First instinct is the right one; if a row takes more than a few seconds it usually means the
task as written isn't a real single thing, which is itself the answer — mark it `?` and move on.

## What comes out of it

- **`nowhere` in column C is the finding.** Work done well and lost. The next one starts from zero.
- **`from scratch` + `remembered` + `nowhere`** is the worst combination and the best target. It happens only
  when someone remembers, gets rebuilt each time, and leaves nothing behind.
- **`standard` + `a system` + `a system`** needs nothing. Skip everything beneath it — those work items are
  already handled.
- **Anything in `backlog.md` that maps to no surviving row here gets struck as a block**, unread. That is how
  115 unreviewed rows get resolved without reading 115 rows.

*Illustration of the shape only — not an answer, and not a claim about how SRND works:*

| ID | Task | A | B | C | Reads as |
|---|---|---|---|---|---|
| — | *(example)* Answer a technical question from a dealer | `from scratch` | `asked` | `a head` | *Happens constantly, well answered, and the answer dies in an inbox — so the same question gets answered again next month* |

## The last question, and it is the one the sheet cannot ask itself

**What do you do that isn't on this list?**

A list only contains what somebody thought of, and these 46 rows were assembled from documents rather than from
watching anyone work. Anything named here is a genuine addition; anything above that turns out not to be a real
single thing gets struck. Both are more valuable than a filled row.
