# Intro-campaign template

A reusable, phased campaign for **introducing a brand to new audiences** — its features, system and
benefits — built around a bold hook and tied into the content that already exists. It maps onto the
buyer journey (`03-buyer-journey.md`) and follows the placement rules (`10-content-placement.md`).

**Origin:** the Fabric Walls intro campaign (the worked example at the end of this document). First
re-applied to C-ATS (`brands/c-ats/content.md`). It's a group template because the shape is the
same for any brand; only the content changes.

> **Use this as a guide, not a script.** These are proven starting points to draw on and adapt —
> not the only thing we can do, and not a mandatory sequence. Add, drop or reorder to fit the brand
> and the moment.

## Principles

1. **A campaign addresses a specific problem or need** — not a general, ongoing feed of content. It
   has a job and an end.
2. **The gap is usually hooks, not depth.** A brand often already has a lot of in-depth content; what
   it lacks are immediate hooks. So the campaign *creates the hooks* and **ties into and supplements**
   existing content (extend it, fill its gaps) rather than rebuilding it.
3. **Lead with a bold, text-forward hook — absorbable in a single image.** The hook has a dual job:
   win immediate interest *or* build recognition for recall in later phases. Either is a win.
4. **Generic category imagery doesn't differentiate at the hook.** A styled whole-room / lifestyle
   shot tends to look like every competitor's; over-stripped product shots are confusing. So
   room/lifestyle imagery is a **secondary contact point, not the opener** — the same "lead simple,
   earn the complex" logic the funnel uses (`03-buyer-journey.md`).
   - **This is about the hook only — not a knock on room imagery as content.** SRND has a large
     library of room renders (dozens, into the hundreds). Turned into **virtual case studies** they
     are genuinely valuable — but the render is only the hook *within* the case study; the **story**
     is what matters (a render on its own is lazy). They earn their place *later* in the journey
     (stages 2–3), not as the cold open. See `06-content-production.md` and `10-content-placement.md`.
   - **Case study — Aphex Twin, "Come to Daddy" remix (Designers Republic).** DR wanted to reuse the
     imagery from the track's Orange Mobile advert for the remix CD — instant public recognition —
     but Orange blocked it on copyright. Instead they used **text describing the advert**: bold,
     clear, and anyone walking into HMV for "that track from the Orange ad" found it. The lesson: a
     concept usually carried by visuals can be carried just as well by **words, if they're bold and
     confident enough.**
   - **Ground the words in a subtle product nod** — a close crop of the real product — that steers
     the viewer rather than showcasing the product, and keep the execution premium (e.g. embossed
     text, not flat print). A promo image in a trade magazine lacks the physical context a CD in a
     jewel case had, so the product fragment recreates it.
5. **Silo the hook around the brand's few core solution types** — a small number of punchy,
   emotive statements, short on detail, one per solution type.

## The four phases (mapped to the buyer journey)

**Phase 1 — The Hook** · buyer-journey stage 1 (get in front of them).
- *Goal:* top-level introduction; key solutions siloed into the brand's core categories; a clear
  message that hooks the viewer — find out more now, or build recall for later phases.
- *Media:* trade-press advert (e.g. EI Magazine), web ad/banner, YouTube advert, LinkedIn (business
  + personal), Instagram, email.
- *Content:* one graphical layout per solution silo; 3–5 colourways of each for variety; formatted
  per platform; a ~15-second YouTube advert.

**Phase 2 — What's possible / the range** · buyer-journey stage 2 (land the proposition).
- *Goal:* show what's possible; the range/products at top level; broad-strokes coverage of
  individual features.
- *Media:* trade-press advertorial, YouTube videos, LinkedIn, Instagram, email.
- *Content:* data cards for each element and panel/product type; YouTube videos showcasing install
  features; brief body text for LinkedIn/email; room-design data cards (a handful of rooms showing
  which styles and elements go where). *Room designs live here, as a secondary contact point — not
  in Phase 1.*

**Phase 3 — Add detail / how it works** · buyer-journey stage 3 (prove it).
- *Goal:* add detail; show exactly how it all works; answer the final questions.
- *Media:* trade-press advertorial, YouTube videos, LinkedIn, email, blogs.
- *Content:* how-to blogs; how-to YouTube videos; room-construction breakdowns; data sheets; longer
  body text for blog/email.

**Phase 4 — Fold in** · buyer-journey stage 6 / ongoing.
- *Goal:* fold the campaign into ongoing marketing; end with a brochure of products and services.
- *Media:* all.
- *Content:* as above, consolidated into brochure(s) — the evergreen collateral a dealer (or the
  group) hands over.

## Origin & worked example: Fabric Walls

Preserved so the specifics aren't lost; these move to a Fabric Walls playbook when one is created.

- **Two solution silos:** (1) *product features & ease of install*; (2) *a system that makes design
  easy*. The hook addresses both.
- **Creative:** text-forward statements over a close-up of **twin Fabric Walls panels and the metal
  frame** — grounding the image in stretch-fabric-panel context without an over-busy full-room shot
  or confusing bare frames. Main text **embossed** for a premium feel (more premium than printing on
  the Ultrasuede fabric itself; note Ultrasuede is a component within Fabric Walls, not a brand —
  `09-brand-portfolio.md`).
- **Why not lead with room imagery:** Fabric Walls room designs are attractors but don't separate
  Fabric Walls from other stretch-fabric systems, so they're a secondary contact point *at the
  hook*. As virtual case studies later in the journey (stages 2–3), the render library is valuable.
- **Phase specifics:** Phase 2 includes room-design data cards for ~5 rooms; media anchored on EI
  Magazine (advert → advertorial), YouTube, LinkedIn, Instagram, email, then blogs in Phase 3.
